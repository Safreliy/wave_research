# Research code

This directory preserves the flat module layout used for the published
calculations so that historical command lines and imports remain valid.

The principal method implementation is in:

- `topography_bie.py` and `topographic_wave_solver.py` for the pre-contact
  Euler--BIE evolution;
- `active_vortex_sheet.py` and `adaptive_vortex_mesh.py` for the circulation
  carrier state and conservative remeshing;
- `vof_handoff.py`, `gpu/project_mac_face_flux.py`, and
  `two_phase_basilisk/prepare_handoff.py` for receiver-grid transfer;
- `two_phase_basilisk/bie_handoff_receiver.c` and `q_embed_vof.h` for the
  post-handoff embedded two-phase calculation.

The manuscript figures are generated by
`near_self_quadrature_study.py`, `plot_mac_face_handoff_audit.py`,
`analyze_impact_claim.py`, `render_impact_grid_comparison.py`,
`analyze_three_grid_morphology.py`, and `render_vorticity_points.py`.
`replot_publication_figures.py` redraws the topology and morphology summary
plots directly from the compact derived evidence included in Git.

Run the complete packaged unit-test suite from the repository root:

```bash
python -m pytest -q research
```

The older exploratory modules are retained when they are dependencies of the
verification suite, but development notes, caches, and obsolete output trees
are not part of this repository.
