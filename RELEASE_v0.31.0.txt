Geometry-consistent conservative transfer of potential-flow states to an embedded-boundary volume-of-fluid solver: code and numerical experiments

Description (paste into the GitHub release):

This release contains the code, article PDF and LaTeX source, figures, and numerical evidence for the study вЂњGeometry-consistent conservative transfer of potential-flow states to an embedded-boundary volume-of-fluid solver.вЂќ It freezes the experiment inputs, selected native solver fields, analysis records, independent audits, and checksums at this version.

The method reconstructs liquid-cell velocity means from a harmonic streamfunction. For thin flat surface strips, both edge averages use a shared boundary trace, so trace error cancels before division by strip thickness. Across 21 analytic initial-field tests, the global velocity error is 2.71вЂ“32.07 times smaller than with a bilinear control using the same streamfunction. At the end of the smooth-wave native continuations, propagated velocity error is 7.88вЂ“10.25 times smaller and surface-profile error is 65.0вЂ“82.9 times smaller relative to numerical trajectories initialized from exact cell means on the same grid. In a separate two-fluid wave test, matched transfer reduces endpoint surface-profile error against a linear analytic reference by 5.49% with the density-weighted mixture assignment held fixed; the complete matched-transfer/mixture-assignment pipeline reduces that error by 52.19% relative to the original practical transfer.

These results concern the tested flat-strip geometries and benchmark settings. The repository also documents the curved-wave compatibility limit and the native solver controls.
